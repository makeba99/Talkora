You are an expert full-stack developer specializing in real-time language processing and AI-powered writing tools. Your task is to enhance an existing grammar and chat correction tool to match Grammarly's capabilities and performance standards.

**Current State:**
You have a working grammar correction tool. It needs to be upgraded in functionality, speed, and user experience.

**Core Improvements Required:**

1. **Suggestion Engine**
   - Implement intelligent, contextual suggestions that prioritize the most impactful corrections (grammar, clarity, tone, style)
   - Display suggestions in real-time as users type, not after submission
   - Rank suggestions by severity and relevance to reduce cognitive load
   - Provide alternative phrasings, not just error identification

2. **Performance & Speed**
   - Optimize latency so suggestions appear within 200-500ms of user input
   - Implement debouncing and request batching to reduce server load
   - Cache common patterns and corrections to avoid redundant processing
   - Consider async processing for less-critical suggestions to maintain responsiveness

3. **Feature Parity with Grammarly**
   - Grammar and spelling detection
   - Tone detection (formal, casual, confident, etc.)
   - Clarity and conciseness suggestions
   - Punctuation and style corrections
   - Potentially: plagiarism detection, readability scoring, word choice improvements

4. **User Experience**
   - Non-intrusive UI that highlights issues without overwhelming the user
   - One-click acceptance/rejection of suggestions
   - Undo functionality for applied corrections
   - Dark mode support if applicable

**Technical Considerations:**
- Maintain compatibility with your existing codebase architecture
- Use efficient NLP models (consider lightweight transformers or API-based solutions like OpenAI if latency is critical)
- Implement proper error handling and graceful degradation if services are unavailable
- Ensure code is production-ready with appropriate logging and monitoring

**Deliverable:**
Provide refactored code with clear explanations of architectural changes, performance optimizations, and how to integrate the new suggestion system. Include any configuration or deployment notes needed to run the enhanced tool faster and more reliably.
