Your ONLY goal: Achieve **100/100 Performance score on Google PageSpeed Insights (Desktop AND Mobile)**.

Ignore SEO, ignore Best Practices, ignore non-performance improvements unless they directly impact performance.

🚨 HARD CONSTRAINT:

* ZERO visual changes (pixel-perfect identical UI)
* ZERO functionality changes
* ZERO UX degradation

## 🎯 REQUIRED METRIC TARGETS

* LCP < 1.5s
* TBT < 100ms
* CLS < 0.05
* INP < 100ms

---

## 🔥 EXECUTION PLAN (MANDATORY ORDER)

1. FIX LCP (HIGHEST PRIORITY)

* Detect the LCP element
* Ensure it is NOT lazy-loaded
* Preload it using:

  <link rel="preload" as="image/font/style/script">
* Apply fetchpriority="high" if image
* Inline ONLY critical CSS required for LCP rendering
* Remove ALL render-blocking resources affecting LCP
* Ensure LCP renders within first viewport immediately

2. ELIMINATE MAIN THREAD BLOCKING (FIX TBT)

* Split all JavaScript bundles aggressively (route + component level)
* Convert non-critical components to dynamic import()
* Defer all non-essential scripts (defer / async)
* Remove unused JS completely
* Move heavy computations off main thread (Web Workers if safe)
* Break long tasks (>50ms)

3. REDUCE JAVASCRIPT PAYLOAD (CRITICAL FOR MOBILE)

* Target total JS < 150KB (ideal)
* Tree-shake everything
* Replace heavy libraries ONLY if behavior remains identical
* Avoid unnecessary polyfills

4. FIX CLS (LAYOUT STABILITY)

* Add width and height to ALL images, avatars, cards
* Reserve layout space BEFORE content loads
* Prevent dynamic content shifting layout
* Use placeholders matching final layout EXACTLY

5. IMAGE OPTIMIZATION

* Convert images to AVIF/WebP (NO visible quality loss)
* Use responsive images (srcset)
* Lazy load ONLY below-the-fold images
* Preload LCP image ONLY

6. CSS OPTIMIZATION

* Remove unused CSS safely
* Inline critical CSS
* Defer non-critical CSS
* Avoid large blocking stylesheets

7. FONT OPTIMIZATION

* Preload critical fonts
* Use font-display: swap WITHOUT layout shift
* Limit font weights and variants

8. NETWORK OPTIMIZATION

* Enable Brotli compression
* Minify all assets
* Use HTTP/2 or HTTP/3
* Add preconnect for required origins

9. THIRD-PARTY CONTROL

* Remove or defer ALL third-party scripts
* Load them AFTER main content is interactive

---

## 📱 MOBILE-FIRST ENFORCEMENT

* Prioritize slow CPU + slow network conditions
* Reduce JS execution time drastically
* Avoid heavy runtime logic during initial load
